# 图片生成来源信息

用户已批准在现有图片悬浮卡中显示模型和线路，并为触屏提供选中图片后的信息入口。

- 桌面悬停 300ms 后显示，拖动、缩放、按下鼠标时关闭；卡片避开屏幕边缘。
- 选中一张已完成图片时，快捷工具栏提供“信息”。详情显示模型、线路、提示词、生成时间、记录的输出尺寸和比例，支持复制名称。
- 每张图片保存 `generationInfo` 快照：来源、模型 ID/名称、线路 ID/名称、生成记录 ID、输出尺寸、比例。服务端实际执行生成记录是权威来源；发起请求时的快照支持等待中和直接 API 生成。
- 新生成、编辑结果、任务恢复、账号历史、本地画布与版本历史均保留快照。上传图明确标为用户上传。去背景等本地处理清除旧生成来源，避免误归因。
- 旧图片仅在当前账号与任务身份匹配且仍展示原始结果时补齐；未知字段显示“未记录”，不使用当前控制面板配置猜测。目录改名或删除不改变已存快照。
- 首版覆盖画布和账号历史中的图片信息，不新增筛选、计费展示或公开供应商内部信息。

验证：请求快照、服务端 get/list 的快照一致性、恢复与账号隔离、编辑不被覆盖、本地持久化、桌面悬停和手机信息弹窗；运行相关测试、类型检查及生产构建。
